How it works

Two requests: one to ask for a link, one when the link is clicked. The browser nonce makes a forwarded or leaked link useless in another browser.

sequenceDiagram
  autonumber
  actor U as User
  participant B as Browser
  participant API as /api/auth/magic-link :::new
  participant DB as Postgres
  participant M as Postmark :::external
  U->>B: Enters email, clicks "Email me a link"
  B->>API: POST { email }
  API->>DB: insert LoginToken (hash, expiresAt, nonce)
  API->>M: send email with /auth/verify?token=…
  API-->>B: 200 ok + Set-Cookie mlnonce
  Note over U,B: User opens the email and clicks the link
  B->>API: GET /auth/verify?token=… (cookie mlnonce)
  API->>DB: find hash, check expiry + nonce, delete row
  alt valid
    API-->>B: createSession() → redirect /dashboard
  else expired, reused, or other browser
    API-->>B: "This link is invalid or expired"
  end
